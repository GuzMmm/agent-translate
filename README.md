# Agent 翻译

一个接入 **OpenAI 兼容 API** 的 Chrome 翻译插件，支持划词翻译、整页翻译、PDF 翻译，目标语言可自选。

## 功能

- **划词翻译**：选中文字即可弹出译文浮层，支持复制、Esc 或点击空白处关闭。
- **整页翻译**：一键把当前网页翻译成目标语言，可一键还原原文。
- **PDF 翻译**：内置 PDF 阅读器，支持划词翻译和整篇双语对照。
- **多语言**：目标语言下拉可选（简中 / 繁中 / 英 / 日 / 韩 / 法 / 德 / 西 / 俄 / 葡 / 意 / 阿 / 印地 / 泰 / 越）。
- **右键菜单**：选中文字后右键即可翻译。

## 安装

1. 打开 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本仓库文件夹
4. 点浏览器工具栏里的插件图标 →「设置」，填入 API 配置即可使用

## 配置

| 项 | 说明 |
| --- | --- |
| Base URL | 填 API 地址，填到 `/v1` 即可；也支持完整地址或只填域名 |
| API Key | `Bearer` 认证的密钥 |
| 模型 | 如 `gpt-4o-mini`、`deepseek-chat` 等 |
| 目标语言 | 翻译的目标语言 |
| Temperature | 0–2，翻译建议填 0.2–0.4 |

Base URL 会自动补全，例如：

- `https://api.openai.com` → `https://api.openai.com/v1/chat/completions`
- `https://api.openai.com/v1` → 同上
- 已带 `/chat/completions` → 原样使用

## 使用

### 划词翻译

选中网页上的文字，稍等即弹出译文浮层，点「复制」可复制译文。

### 整页翻译

点插件图标 →「翻译本页」。翻译完成后点「还原原文」即可恢复。

### PDF 翻译

打开方式（任选其一）：

1. 点插件图标 →「打开 PDF 翻译阅读器」（当前页是 PDF 时会自动加载该文件）；
2. 在任意 PDF 链接上右键 →「用翻译阅读器打开 PDF」；
3. 在阅读器里点「打开文件」，或直接把 PDF 文件拖入窗口。

> 扫描版 PDF 没有文本层，无法划词翻译，需要先做 OCR。

## 常见问题

**需要网络和 API 额度吗？** 需要。本插件通过你在设置里填的 Base URL + API Key 调用接口。

**API Key 要写进代码里吗？** 不用。Key 只保存在浏览器本地存储中，不会写入任何仓库文件。

**为什么输入框、代码块没被翻译？** 这是有意的：`input`/`textarea`/`code`/`pre` 等默认跳过，避免破坏可交互内容。

**翻译本地文件（file:// 网页）没反应？** 需要在 `chrome://extensions` 里给本插件开启「允许访问文件网址」。
